# КП GRAFF.estate с ИИ-агентом

Набор правил и инструментов, по которому ИИ-агент (Claude Code, Codex или другой с доступом к файлам и терминалу)
помогает менеджеру проекта подготовить КП: смету в Google Sheets, колоду в Figma и PDF.

Это не программа с кнопками. Вы ведёте диалог с агентом, а этот набор говорит ему, в каком порядке работать,
какие правила применять и чего не делать без вас.

## Как это работает

| Шаг | Что делает агент | Что делаете вы |
|---|---|---|
| 1. Старт | Заводит папку проекта и файл `CONTEXT.md` | Даёте ссылку на оценку тимлида и материалы клиента |
| 2. Анкета | Задаёт 7 вопросов со своими рекомендациями | Отвечаете: тип объекта, интерьеры отдельно или нет, уровни и так далее |
| 3. Сопоставление | Раскладывает строки тимлида по строкам шаблона и показывает таблицу | Подтверждаете или правите |
| 4. Материалы | Смотрит генплан, АГР, рендеры и предлагает, где можно сократить часы | Утверждаете сокращения |
| 5. Смета | Заполняет копию шаблона: часы, примечания «было / стало / почему», цвета | Смотрите таблицу, показываете руководителю |
| 6. Правки | Вносит правки руководителя, не затирая ваши ручные изменения | Пересказываете правки |
| 7. Колода | Через плагин переносит цифры и тексты в копию КП в Figma | Открываете файл и запускаете плагин |
| 8. PDF | Выгружает колоду в сжатый PDF | Отправляете клиенту |

Результат на каждом шаге — обычная Google-таблица и обычный файл Figma. Их можно править руками, показывать
и передавать без агента.

Решения по КП принимаете вы. Агент не придумывает цены, сроки, скидки и новые пункты работ: он спрашивает.

## Что внутри

| Путь | Что это |
|---|---|
| `AGENTS.md` | Инструкция для агента: порядок работы и границы. Агент читает её первой |
| `rules/core.md` | Ядро правил: смета, уровни, Figma, сверка, журнал случаев. Обновляется автором набора |
| `rules/intake.md` | Анкета перед расчётом |
| `rules/materials.md` | Как разбирать материалы клиента |
| `MY-RULES.md` | Ваши правила и ссылки. Имеют приоритет над ядром, обновлениями не затираются |
| `templates/` | Карта слайдов КП и шаблон `CONTEXT.md` |
| `tools/` | Плагин Figma и мост, выгрузка PDF, скачивание с Яндекс Диска |
| `examples/brigli/` | Эталонное КП для проверки, что всё работает |
| `projects/` | Ваши проекты. В общий репозиторий не попадают |

## Установка

1. Нужны: Git, Node.js 18 или новее, Python 3 с пакетами `pymupdf` и `pillow` (`pip install pymupdf pillow`),
   Figma Desktop, ИИ-агент с доступом к папке и терминалу.
2. Склонируйте репозиторий и откройте папку в агенте.
3. Запустите проверку: `bash check.sh`. Она создаст `MY-RULES.md` и покажет, чего не хватает.
4. Заполните в `MY-RULES.md` раздел «Мои ссылки»: шаблон расчёта, папка на Google Drive, последнее КП в Figma.
5. Дайте агенту доступ к Google Sheets и Drive (в Claude — коннекторы Google; в другом агенте — его способ).
6. В Figma Desktop один раз: Plugins → Development → Import plugin from manifest → `tools/figma-plugin/manifest.json`.
7. Установите шрифты, в которых свёрстаны колоды команды (TT Hoves Pro и другие). Если Figma при открытии файла
   пишет «Missing fonts», плагин не сможет менять тексты.

## Проверка на эталоне

Попросите агента: «Собери смету по эталону `examples/brigli` в копии шаблона расчёта и сверь с ожидаемым результатом».
Если часы и итоги совпали с `examples/brigli/README.md` — набор работает.

## Как начать новое КП

Напишите агенту, например:

> Делаем новое КП: <застройщик>, <объект>, <город>. Оценка тимлида: <ссылка>. Материалы клиента: <ссылка>.

Дальше он пойдёт по шагам из таблицы выше.

## Свои правила и обновления

- Агент ошибся, и это повторится в следующих КП — попросите его записать правило в `MY-RULES.md`.
- Обновления ядра: `git pull`. `MY-RULES.md` и `projects/` при этом не меняются.
- Правило из ядра вам не подходит — не правьте `rules/core.md`, запишите своё в `MY-RULES.md`: оно важнее.
- Нашли в ядре ошибку или полезное общее правило — напишите автору набора.

## Чего набор не делает

- Не заменяет согласование с руководителем: таблицу и колоду вы показываете сами.
- Не знает ставок и себестоимости — они в шаблоне расчёта.
- Не стандартизует оценку тимлида: её разбирает агент, а вы подтверждаете.
